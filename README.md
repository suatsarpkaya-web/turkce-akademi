Türkçe Akademi - Yabancılar İçin Türkçe Portalı
Türkçe Akademi, yabancılara Türkçe öğretimini modern, etkileşimli ve kültürel bağlamla zenginleştirilmiş bir metodolojiyle sunan açık kaynaklı bir web portalıdır.
🌟 Öne Çıkan Özellikler
Duyarlı Tasarım (Responsive Layout): Masaüstü, tablet ve mobil cihazlarda (iOS & Android) kusursuz görüntüleme ve kullanılabilirlik.
Kategorili Kelime Öğrenme Modülü: Tanışma, Hayvanlar, Yiyecekler, Mekanlar ve Günlük İfadeler şeklinde ayrılmış tematik kelime panelleri.
Sesli Telaffuz Desteği (Text-to-Speech): Web Speech API kullanılarak yerleşik olarak çalışan, doğru Türkçe okunuş simülasyonu.
Canlı Quiz & Kendini Dene: Kullanıcının gramer ve atasözü bilgisini anında ölçen, açıklamalı geri bildirim sunan interaktif test sistemi.
Site İçi Arama Çubuğu (Header Search): Üst barda yer alan arama girdisi ile blog yazılarında ve kelime haznelerinde anında arama.
Kültür Blogu & Modal Detaylar: Türk kahvesi geleneği, İstanbul ve sanat, misafirperverlik gibi kültürel konuları içeren detaylı okuma metinleri.
TDK Sözlük Entegrasyonu: Türk Dil Kurumu resmi sözlüğüne doğrudan erişim bağlantısı.

🚀 Kurulum ve Çalıştırma
Proje herhangi bir derleme (build) veya harici paket bağımlılığı gerektirmez. Standard HTML5, CSS3 ve Vanilla JavaScript kullanılarak geliştirilmiştir.
Proje dosyalarını bilgisayarınıza indirin veya klonlayın:
git clone <https://github.com/kullaniciadi/turkce-akademi.git>
​
Proje dizinine gidin:
cd turkce-akademi
​
index.html dosyasını herhangi bir modern web tarayıcısında (Google Chrome, Mozilla Firefox, Safari, Microsoft Edge) çift tıklayarak açın.
🛠️ Kullanılan Teknolojiler
HTML5: Semantik etiket yapısı.
CSS3: Custom Properties (CSS Değişkenleri), Flexbox, CSS Grid ve Media Queries.
JavaScript (ES6+): DOM Manipülasyonu, Event Listener'lar ve Web Speech API (window.speechSynthesis).
Google Fonts: Poppins ve Merriweather font aileleri.
