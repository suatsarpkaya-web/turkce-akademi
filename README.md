## 📖 Hakkında

**Türkçe Akademi**, yabancılara Türkçe öğretimini modern bir arayüz ve kültürel içeriklerle sunan açık kaynaklı bir web portalıdır. Kelime öğrenme, sesli telaffuz, interaktif quiz ve kültür yazılarını tek bir sayfada buluşturur.

Proje herhangi bir derleme (build) adımı veya harici paket gerektirmez; saf HTML, CSS ve JavaScript ile geliştirilmiştir ve Vercel üzerinde yayınlanmıştır.

> 🔗 **Canlı demo:** https://turkce-akademi.vercel.app/

---

## 🌟 Öne Çıkan Özellikler

| Özellik | Açıklama |
|---|---|
| 📱 **Duyarlı Tasarım** | Masaüstü, tablet ve mobil cihazlarda (iOS & Android) sorunsuz görüntüleme ve kullanım. |
| 🗂️ **Kategorili Kelime Modülü** | Tanışma, Hayvanlar, Yiyecekler, Mekanlar ve Günlük İfadeler başlıklarında tematik kelime panelleri. |
| 🔊 **Sesli Telaffuz** | Web Speech API ile doğru Türkçe okunuşun sesli olarak dinlenmesi (Text-to-Speech). |
| 🧠 **Canlı Quiz & Kendini Sına** | Gramer ve atasözü bilgisini anında ölçen, açıklamalı geri bildirim sunan interaktif test sistemi. |
| 🔍 **Site İçi Arama** | Üst çubuktaki arama alanıyla blog yazıları ve kelime listelerinde anında arama. |
| ☕ **Kültür Blogu & Modal Detaylar** | Türk kahvesi geleneği, İstanbul ve sanat, misafirperverlik gibi konularda detaylı okuma metinleri. |
| 📚 **TDK Sözlük Bağlantısı** | Türk Dil Kurumu resmi sözlüğüne doğrudan erişim. |

## 📁 Proje Klasör Yapısı

```
turkce-akademi/
│
├── index.html   # Ana sayfa: görseller, kelime panelleri, quiz ve blog yapısı
├── style.css    # Renk paleti, Flexbox/Grid düzeni ve responsive kurallar
└── script.js    # Kategori geçişleri, sesli telaffuz, quiz ve arama mantığı
```

## 🚀 Kurulum ve Çalıştırma

Proje herhangi bir derleme adımı ya da harici paket gerektirmez. Standart HTML5, CSS3 ve Vanilla JavaScript ile çalışır.

**1. Depoyu klonlayın**

```bash
git clone https://github.com/kullaniciadi/turkce-akademi.git
```

**2. Proje dizinine geçin**

```bash
cd turkce-akademi
```

**3. Çalıştırın**

`index.html` dosyasını herhangi bir modern tarayıcıda (Chrome, Firefox, Safari, Edge) çift tıklayarak açmanız yeterlidir.

---

## 🛠️ Kullanılan Teknolojiler

- **HTML5**: Semantik etiket yapısı
- **CSS3**: CSS değişkenleri (Custom Properties), Flexbox, CSS Grid ve Media Queries
- **JavaScript (ES6+)**: DOM manipülasyonu, Event Listener'lar ve Web Speech API (`window.speechSynthesis`)
- **Google Fonts**: Poppins ve Merriweather yazı tipi aileleri
- **Vercel**: Yayınlama ve barındırma
